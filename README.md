# פתקי משימות (Notes App)

אפליקציית פתקי משימות בעברית (RTL) שרצה בדפדפן, מותקנת כ-PWA, וזמינה גם כ-APK לאנדרואיד.

**כתובת האתר:** https://aquaadir141-code.github.io/notes-app/

## Features

- יצירת פתקים עם צבע, תאריך יעד ונעיצה (📌) לראש הרשימה.
- תיקיות: "תיקייה כללית", "משימות שהושלמו" ו"אשפה" קבועות, ואפשר להוסיף תיקיות משלך ולבחור להן צבע.
- חיפוש פתקים, מצב יום/לילה, ותצוגת לוח (📋) שבה גוררים פתקים ומשנים את גודלם.
- תזכורות: כשמגיע תאריך היעד של פתק מתנגן צליל (אחד משלושה לבחירה) ומוצגת התראה, אם אישרת התראות.
- גיבוי ושחזור לקובץ JSON (פירוט בהמשך).
- עובד גם בלי אינטרנט אחרי הטעינה הראשונה, בזכות Service Worker (`sw.js`).

## Project structure

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף ורישום ה-Service Worker |
| `script.js` | כל הלוגיקה: פתקים, תיקיות, תזכורות, גיבוי ושחזור |
| `styles.css` | עיצוב |
| `sw.js` | מטמון לעבודה offline והצגת התראות |
| `manifest.json` | הגדרות PWA (שם, אייקונים, RTL) |
| `sound 1.wav` … `sound 3.wav` | צלילי התזכורת |
| `android/` | עטיפת WebView לאנדרואיד |
| `.github/workflows/build-apk.yml` | בניית APK ופרסום Release |

אין שלב build ואין תלויות: זה HTML, CSS ו-JavaScript רגילים.

## Run locally

צריך להריץ דרך שרת סטטי ולא לפתוח את `index.html` ישירות מהקובץ, כי Service Worker והתראות לא עובדים מ-`file://`.

מתיקיית הפרויקט, אחת מהאפשרויות:

<div dir="ltr">

```bash
python3 -m http.server 8000
# או
npx serve .
```

</div>

ואז לפתוח את http://localhost:8000.

אחרי שינוי בקבצים, אם הדפדפן ממשיך להציג גרסה ישנה, זה המטמון של ה-Service Worker. אפשר לרענן עם Ctrl+Shift+R, או להעלות את `CACHE_NAME` ב-`sw.js` (למשל מ-`v2` ל-`v3`) כדי שכל המשתמשים יקבלו את הקבצים החדשים.

## Deploy (GitHub Pages)

האתר מוגש מ-GitHub Pages מתוך ענף `main`. כל push ל-`main` מתפרסם אוטומטית בכתובת https://aquaadir141-code.github.io/notes-app/ תוך כמה דקות.

## Android APK

התיקייה `android/` היא אפליקציית אנדרואיד מינימלית (`MainActivity.java`) שפותחת WebView על כתובת ה-GitHub Pages. לכן כל עדכון לאתר מגיע גם לאפליקציה בלי לבנות APK חדש.

ה-workflow ‏`build-apk.yml` רץ בכל push ל-`main` (או ידנית מלשונית Actions):

1. מתקין Java 17, Android SDK ו-Gradle.
2. מעתיק את `icon-192.png` ו-`icon-512.png` כאייקוני האפליקציה.
3. בונה APK במצב release (`gradle assembleRelease`).
4. מעלה את ה-APK כ-artifact ויוצר GitHub Release בשם `v1.0.<מספר הריצה>` עם הוראות התקנה.

**התקנה בטלפון:** מורידים את ה-APK מה-[Release האחרון](https://github.com/aquaadir141-code/notes-app/releases/latest), מאשרים התקנה ממקורות לא ידועים, ופותחים את הקובץ.

הערות:
- ה-APK חתום במפתח debug ו-`versionCode` קבוע על 1 (`android/app/build.gradle`), כך שהתקנת גרסה חדשה מעל ישנה עלולה להיכשל.
- הסרת האפליקציה מוחקת את הפתקים שבה. כדאי לגבות לפני.

## Data storage

כל הנתונים נשמרים **מקומית במכשיר**, ב-`localStorage` של הדפדפן (או של ה-WebView באנדרואיד). אין שרת ואין סנכרון בין מכשירים.

| מפתח | תוכן |
|---|---|
| `notes` | רשימת הפתקים |
| `folders` | התיקיות שהמשתמש יצר |
| `folderColors` | צבעי התיקיות |
| `notePositions` | מיקום וגודל הפתקים בתצוגת הלוח |
| `darkMode`, `selectedColor`, `selectedSound` | העדפות |

בנוסף, IndexedDB בשם `notesBackupDB` שומר את תיקיית הגיבוי שנבחרה (בדסקטופ).

ניקוי נתוני האתר בדפדפן, או הסרת האפליקציה באנדרואיד, מוחק את כל הפתקים.

## Backup & restore

הכפתורים נמצאים בתחתית תפריט התיקיות (☰).

**גיבוי** יוצר קובץ `notes_backup_YYYY-MM-DD.json` עם הפתקים, התיקיות, הצבעים ומיקומי הלוח:
- **בטלפון:** נפתח חלון שיתוף, וממנו שומרים את הקובץ (לדרייב, לוואטסאפ לעצמך וכו').
- **בדסקטופ (Chrome/Edge):** בפעם הראשונה בוחרים תיקייה, והיא נזכרת לגיבויים הבאים.
- **בדפדפנים אחרים:** הקובץ פשוט יורד.

**גיבוי אוטומטי:** אם נבחרה תיקיית גיבוי בדסקטופ והאפליקציה פתוחה בשעה 16:00, נשמר גיבוי אחד ביום לאותה תיקייה.

**שחזור** טוען קובץ גיבוי JSON ו**מחליף** את הפתקים והתיקיות הקיימים בתוכן הקובץ (לא ממזג). אם יש פתקים שלא מופיעים בגיבוי, כדאי לגבות אותם קודם.

## Known limitations

- תזכורות על תאריך יעד נבדקות כל 5 שניות רק כשהאפליקציה פתוחה. כשהיא סגורה לא תגיע התראה.
- אין סנכרון בין מכשירים. מעבירים פתקים ביניהם דרך גיבוי ושחזור.
